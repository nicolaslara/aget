# aget

Agent get: a local-first, auth-aware URL-to-agent-context tool inspired by `wget`, `curl.md`, and Firecrawl.

See [`project.md`](./project.md) for the original goal, [`AGENTS.md`](./AGENTS.md) for agent instructions, and [`WORKING.md`](./WORKING.md) for the living project workflow.

OpenCode project commands live in `.opencode/commands/`; `/next` is defined there. Cursor-compatible commands live in `.cursor/commands/`.
