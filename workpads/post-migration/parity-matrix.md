license-aware, behavior-level adapted tests when safer.

- `covered`: current local tests directly cover the behavior.
- `partial`: current tests cover the behavior shape but leave a meaningful gap.
- `gap`: implemented behavior has no adequate deterministic local test.
- `not-applicable`: upstream behavior is outside current `aget` scope.
